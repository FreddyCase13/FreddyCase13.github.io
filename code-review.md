This is my code review where I walk through three artifacts from my Computer Science program. Here, I explain what the code does, review it against a code review checklist, and discuss my plan to enhance them.

## Software Design and Engineering
**3D OpenGL Scene (CS 330)**

This is my 3D desk scene written in C++ and rendered in OpenGL. The review covers the "SceneManager" class which handles every object by name. I also discuss my plan to create a shared base class that all objects will inherit from.

## Algorithms and Data Structures
**Course Planner (CS 300)**

A C++ program that loads courses into a binary search tree. The review highlights the code of an unbalanced tree and a search bug. I also share my plan to build a hash table and how I will create a benchmark test between the binary search tree and the hash table.

## Databases
**Grazioso Salvare Dashboard (CS 340)**

A dashboard written in Python and that utilizes MongoDB that is for a fictional animal rescue company. The review covers issues like hardcoded database credentials and inefficient queries. I also discuss my plan to fix both.
